# CMT-FINE：面向小目标相位稳定性的守恒矩检测

> 本文档是完整论文的最小核心。它只保留论文必须讲清楚的观点、方法和证据链。后续的相关工作、完整推导、实现细节、实验数据和图表，都应从这条主线展开。

## 全文的一个核心观点

小目标只占少量像素。当目标相对采样网格移动一两个像素时，目标外观几乎没有改变，但卷积和降采样看到的像素组合可能明显改变，最终造成漏检、置信度波动或定位偏移。我们把这种现象称为**小目标的采样相位敏感性**。

CMT（Conservative Moment Transport，守恒矩输运）不试图阻止所有特征变化，而是在特征聚合过程中显式保存目标证据的三个基本几何量：**有多少、在哪里、如何分布**。CMT-FINE将这些较稳定的几何信息用于修正D-FINE的边界分布，使检测器在保持高检测精度的同时，对小目标的采样相位变化更加稳定。

全文的逻辑只有四步：

1. 小目标存在比中大目标更严重的采样相位敏感性。
2. 其关键原因之一，是少量空间证据在降采样时容易随网格划分改变或丢失。
3. CMT通过守恒的低阶矩保存并传递这些空间证据。
4. CMT-FINE用CMT提供的几何信息约束D-FINE的定位结果，并通过实验验证精度和相位稳定性的改善。

---

## 摘要

小目标检测通常关注特征弱、分辨率低和背景干扰，却较少研究目标相对采样网格的位置。对于仅占少量像素的目标，一像素平移就可能改变卷积和降采样过程中的像素分组，使同一目标在不同采样相位下产生不同的检测结果。该问题在反无人机场景中尤其重要，因为远距离无人机尺寸小且持续运动，会不断经过不同的采样相位。

本文首先通过受控整数平移实验研究小目标的采样相位敏感性。实验保持图像内容和模型参数不变，只改变目标相对采样网格的位置，并将预测框映射回原坐标系进行比较。跨模型、跨数据集结果用于回答两个问题：小目标是否比中大目标更容易发生检测翻转，以及这种不稳定是否能够独立于平均检测精度被观察到。

为减少特征聚合造成的细粒度几何损失，本文提出守恒矩输运CMT。CMT将非负目标证据表示为质量、一阶矩和二阶矩，并利用确定的坐标变换公式完成跨区域、跨尺度合并。质量表示证据强度，一阶矩表示证据中心，二阶矩表示证据的空间分布。无论局部区域以何种顺序合并，只要底层证据相同，合并后的低阶矩保持一致。

在此基础上，本文以D-FINE为强基线构建CMT-FINE。D-FINE负责提取语义并预测精细的边界分布，CMT负责提供显式、可追踪的局部几何证据。查询在当前预测框附近读取CMT矩信息，生成矩引导的候选边界分布，并根据证据可靠性决定修正强度。实验将同时评价COCO检测指标、小目标检测指标、采样相位翻转率、定位波动和计算开销，以验证CMT-FINE是否真正改善小目标检测及其相位稳定性。

## 1. 引言

### 1.1 问题

远距离无人机往往只占几个到几十个像素。像素少会带来两个直接后果：

- 目标信息容易被背景淹没；
- 很小的定位或特征变化，也会占据目标尺寸的较大比例。

现有研究主要通过高分辨率特征、多尺度融合、注意力或更强的检测头增强小目标。然而，这些方法通常没有直接回答一个更基础的问题：

> 当目标内容几乎不变，只相对采样网格移动一两个像素时，检测结果是否稳定？

这种移动会改变目标像素落入卷积窗口和降采样单元的方式。对于大目标，变化只影响目标的一小部分；对于小目标，它可能改变大部分有效证据。因此，同一个小目标可能在一个位置被正确检测，在相邻位置却被漏检或错误定位。

### 1.2 为什么反无人机场景更需要相位稳定性

反无人机检测面对的不是静止图像中的偶然平移，而是移动目标连续经过不同采样相位的过程。如果检测器对相位敏感，视频中可能出现：

- 相邻帧检测结果反复出现和消失；
- 置信度在阈值附近剧烈波动；
- 预测框跳动，影响后续跟踪和告警。

因此，平均AP并不能完整描述反无人机场景中的检测质量。模型还应在目标外观基本不变时给出稳定的检测结果。

### 1.3 现有方法的缺口

普通特征可以学习位置信息，但网络没有被明确要求在降采样和多尺度聚合时保存局部证据的几何统计。更强的语义特征可以回答“这里像不像目标”，却不保证稳定保存：

- 目标证据有多少；
- 证据中心在哪里；
- 证据在空间中如何展开。

D-FINE通过细粒度边界分布提高定位能力，但精细的输出形式并不自动保证输入侧的细粒度几何证据在特征压缩中得到保留。这正是CMT要补充的信息。

### 1.4 本文方法

本文提出CMT，用具有明确空间意义的低阶矩描述目标证据，并在特征聚合时按照解析公式输运这些矩。随后，将CMT嵌入D-FINE，构成CMT-FINE：

- D-FINE提供强语义表示和精细边界分布；
- CMT提供显式的局部几何中心与分布；
- 矩引导精修将两类信息结合；
- 可靠性控制避免错误几何证据过度修改原预测。

### 1.5 贡献

本文的核心贡献为：

1. **提出并系统研究小目标的采样相位稳定性问题。**通过可回映射的受控平移实验，比较不同尺度目标的检测翻转、置信度变化和定位波动，并分析该问题在反无人机场景中的实际意义。
2. **提出守恒矩输运CMT。**CMT显式保存目标证据的质量、中心和空间分布，并通过可合并的矩输运公式减少特征聚合造成的几何信息损失。
3. **提出CMT-FINE。**该模型把CMT的几何证据用于D-FINE边界分布精修，在强基线上检验检测精度与相位稳定性是否能够同时改善。

## 2. 小目标的采样相位稳定性问题

### 2.1 什么是采样相位

设输入图像为 \(I\)，将图像平移整数像素 \(\delta=(\delta_x,\delta_y)\)，得到 \(T_\delta I\)。平移没有改变目标类别，只改变目标相对卷积和降采样网格的位置。这个相对位置称为采样相位。

检测 \(T_\delta I\) 后，将预测框反向平移到原图坐标。如果模型稳定，反向映射后的结果应与原图结果接近：

\[
T_{-\delta}F(T_\delta I)\approx F(I).
\]

这里要求的是检测结果随目标一起移动，即**平移等变**，不是要求预测框在平移前后保持相同坐标。

### 2.2 为什么小目标更敏感

小目标的相位敏感性来自两种作用：

1. **证据变化更大。**目标只有少量像素，网格移动后进入不同采样单元，聚合后的目标与背景比例可能明显改变。
2. **误差影响更大。**相同的一像素定位偏差，在小框中占比更高，更容易使IoU下降并跨过匹配阈值。

因此，完整分析必须同时测量检测翻转和连续定位误差，不能只根据PFR判断模型内部特征是否稳定。

### 2.3 本文要验证的现象

问题实验需要验证：

- 小目标的检测翻转率是否高于中大目标；
- 只统计至少在一个相位被检出的实例后，该现象是否仍存在；
- 小目标的置信度、中心和边界波动是否更大；
- 结果是否能够在多个检测器和多个数据集上复现。

这组实验只证明问题存在，不能单独证明CMT有效。

## 3. 守恒矩输运CMT

### 3.1 直观解释

CMT把目标证据看成分布在图像平面上的“质量”。对一个局部区域，CMT不保留所有像素，而是保留三个层次的信息：

| 几何量 | 直观含义 | 回答的问题 |
|---|---|---|
| 质量 \(m\) | 证据总强度 | 有多少证据 |
| 一阶矩 \(\mathbf p\) | 带坐标的证据总和 | 证据中心在哪里 |
| 二阶矩 \(\mathbf Q\) | 证据相对坐标的展开 | 证据如何分布 |

这些量比单纯的池化值多保留了几何位置，又远比保存完整高分辨率特征便宜。

### 3.2 数学定义

设位置 \(\mathbf x_i=(x_i,y_i)^\top\) 的非负证据为 \(e_i\ge 0\)。局部区域的CMT状态定义为：

\[
m=\sum_i e_i,\qquad
\mathbf p=\sum_i e_i\mathbf x_i,\qquad
\mathbf Q=\sum_i e_i\mathbf x_i\mathbf x_i^\top .
\]

由此得到证据中心和空间协方差：

\[
\mathbf c=\frac{\mathbf p}{m},\qquad
\mathbf\Sigma=\frac{\mathbf Q}{m}-\mathbf c\mathbf c^\top .
\]

\(m\)描述证据强度，\(\mathbf c\)描述证据中心，\(\mathbf\Sigma\)描述证据在水平、垂直和斜向上的分布。

### 3.3 为什么称为“守恒输运”

假设第 \(k\) 个子区域在自己的坐标原点下具有状态
\((m_k,\mathbf p_k,\mathbf Q_k)\)，其原点相对父区域原点的位移为
\(\mathbf d_k\)。合并后的状态为：

\[
m=\sum_k m_k,
\]

\[
\mathbf p=\sum_k(\mathbf p_k+m_k\mathbf d_k),
\]

\[
\mathbf Q=\sum_k\left(
\mathbf Q_k+
\mathbf d_k\mathbf p_k^\top+
\mathbf p_k\mathbf d_k^\top+
m_k\mathbf d_k\mathbf d_k^\top
\right).
\]

这些公式只是坐标变换与求和，不依赖学习参数。它带来一个关键性质：

> 对同一底层证据区域，先分块再合并与直接计算得到相同的低阶矩。

因此，CMT不会在尺度合并时再次丢失已经进入矩状态的质量、中心和二阶分布。神经网络负责学习“哪些位置是目标证据”，CMT负责按确定规则保存和传递“这些证据在哪里”。

### 3.4 CMT能够解决什么

CMT的作用不是让整套检测器严格平移等变，也不能恢复已经被证据提取器完全丢失的目标。它解决的是更具体的问题：

> 当目标证据已经形成后，避免后续分块、换原点和跨尺度合并继续丢失其低阶几何信息。

这也是CMT的创新核心：把学习得到的语义证据与具有明确变换规律的几何状态分开，再在检测阶段重新结合。

## 4. CMT-FINE

### 4.1 为什么基于D-FINE

D-FINE使用分布形式预测目标四条边，具有较强的定位能力，适合作为检验CMT的强基线。但D-FINE的边界分布主要由语义特征和查询状态产生，没有显式使用一个跨尺度守恒的局部证据中心。

CMT-FINE并不替换D-FINE，而是补充其定位依据：

- D-FINE回答目标是什么、边界可能在哪里；
- CMT回答局部目标证据集中在哪里、分布是否可靠。

### 4.2 数据流

数据流可以概括为：

> 输入图像 → D-FINE语义特征与查询 → D-FINE基础边界分布  
> 输入图像与语义特征 → 非负证据 → CMT矩表示 → 查询局部矩  
> 基础边界分布＋局部矩 → 矩引导候选分布 → 可靠性控制 → 最终预测

模型包含四个关键步骤：

1. **证据构建。**融合浅层细节与深层语义，产生多个非负证据基。
2. **守恒聚合。**为证据计算质量、一阶矩和二阶矩，并构建多尺度矩表示。
3. **查询读取。**每个D-FINE查询根据自身语义，在当前预测框附近选择证据和读取尺度，得到局部矩中心。
4. **边界精修。**以局部矩中心为几何参考，对D-FINE四边分布产生一个候选修正，并预测修正强度。

### 4.3 矩如何作用于D-FINE

设D-FINE原始四边分布为 \(P^0\)，CMT根据局部矩中心生成候选分布 \(P^C\)。最终分布为：

\[
P^{out}=(1-\alpha)P^0+\alpha P^C,\qquad 0\le\alpha\le1.
\]

\(\alpha\)表示CMT证据的使用强度：

- 证据可靠时，模型更多使用矩引导结果；
- 证据含混或与查询不一致时，模型保留D-FINE原预测；
- 小目标允许更大的修正预算，因为其更容易受相位和定位误差影响。

这种设计保留了D-FINE的语义与边界分布能力，同时为四条边提供共同的几何参照。

### 4.4 训练目标

CMT-FINE保留D-FINE原有检测损失，并加入少量辅助监督：

- 证据损失：使证据集中在真实目标附近；
- 矩中心损失：使读取到的几何中心接近真实目标中心；
- 候选框损失：保证矩引导候选本身具有定位能力；
- 强度选择损失：学习何时使用以及使用多少CMT修正。

论文的核心不是“增加四个损失”，而是让CMT形成一条从证据、守恒矩到最终边界分布的完整学习路径。

## 5. 实验

实验必须围绕四个问题组织，而不是按模块堆叠结果。

| 研究问题 | 必须提供的证据 |
|---|---|
| Q1：小目标是否存在更严重的相位敏感性？ | 多模型、多数据集的受控平移实验 |
| Q2：CMT-FINE是否提高检测能力？ | 与同训练设置D-FINE比较AP、AR及小目标指标 |
| Q3：提升是否来自CMT机制？ | 矩阶数、守恒合并、证据、精修和强度控制消融 |
| Q4：CMT-FINE是否改善相位稳定性？ | 在精度和召回不下降的前提下比较PFR及连续波动 |

### 5.1 问题验证实验

在冻结模型和预处理设置下，对输入执行受控整数平移。预测框回映射到原坐标后，对同一GT实例进行比较。至少报告：

- phase flip rate（PFR）：不同相位间检出状态发生翻转的比例；
- phase-0 dropout：原始相位检出、其他相位漏检的比例；
- 置信度波动；
- 中心偏移、边界偏移和IoU波动；
- 每个尺度组的实例数与基础召回率。

尺度应按模型实际输入后的目标面积划分。论文关注的极小目标组为
\(w\times h<10\times10\)，同时报告 \(10\times10\) 到 \(32\times32\)
及更大目标，避免把不同尺度现象混在一起。

### 5.2 检测性能实验

CMT-FINE与D-FINE必须使用相同的数据划分、输入尺寸、训练轮数和评测代码。报告：

- COCO AP、AP50、AP75和AR；
- COCO small、medium、large指标；
- 输入图像中面积小于 \(10\times10\) 像素目标的AP和AR；
- 参数量、FLOPs、显存和推理延迟。

### 5.3 核心消融

最小消融集合为：

| 实验 | 要回答的问题 |
|---|---|
| D-FINE baseline | 强基线性能 |
| 加入等参数普通精修分支 | 收益是否只是来自额外参数 |
| CMT仅质量 | 只有证据强度是否足够 |
| CMT质量＋一阶矩 | 显式中心是否有效 |
| CMT完整二阶矩 | 空间分布是否提供额外收益 |
| CMT但不修改边界 | 仅辅助监督能否解释收益 |
| 固定修正强度 | 自适应可靠性控制是否必要 |
| 完整CMT-FINE | 所有设计共同作用 |

### 5.4 判断论文结论是否成立

PFR下降本身不能证明模型更好，因为一个始终漏检的模型同样不会发生翻转。因此，核心结论必须同时满足：

1. 整体AP和小目标AP不低于D-FINE；
2. 小目标召回率没有因保守预测而下降；
3. 在相同实例集合或明确条件集合上，PFR和定位波动下降；
4. 多个随机种子或置信区间支持结果不是偶然波动。

只有同时满足这些条件，才能得出“CMT-FINE提高了小目标检测能力和相位稳定性”的结论。

## 6. 论文结论

本文研究了小目标检测中一个容易被平均精度掩盖的问题：同一目标仅相对采样网格移动少量像素，就可能产生不同的检测结果。该问题对只占少量像素且持续运动的无人机目标尤其重要。

针对特征聚合中细粒度几何容易丢失的问题，本文提出CMT。CMT用质量、一阶矩和二阶矩描述学习到的目标证据，并通过确定的坐标变换实现守恒合并。基于CMT构建的CMT-FINE，将局部矩中心作为D-FINE边界分布的补充几何依据，并根据证据可靠性控制修正强度。

论文最终需要通过实验回答一个明确的问题：

> 在不牺牲检测精度和召回率的前提下，显式保存并使用局部证据的低阶几何，能否让小目标检测更加准确、更加稳定？

如果答案成立，本文的价值不仅是提出一个新的检测模块，也说明了小目标检测除语义增强和分辨率提升之外，还存在一条值得研究的方向：**在特征压缩过程中显式保存具有确定变换规律的几何信息。**

## 7. 后续扩写原则

后续完整论文应围绕这份最小核心扩写，不改变中心命题：

- Related Work用于说明相位稳定性、小目标检测和分布式边界回归的研究位置；
- Method补充CMT的完整推导、张量结构、复杂度和CMT-FINE实现；
- Experiments填入真实数据、统计检验、可视化和失败案例；
- Discussion明确CMT不能恢复已消失目标证据、不能保证整网严格等变等边界。

任何新增模块都必须回答“它在问题—CMT—CMT-FINE—实验这条链中解决了什么必要问题”。如果不能增强这条主线，就不应成为论文的核心贡献。
