# CMTDet 消融实验指南

## 1. 先明确要回答的问题

核心问题是：坐标一致的矩保留与读出，是否在相同训练预算下改善小目标检测和相位稳健性。需要区分证据监督、额外参数、保留高分辨率、矩阶数、运输机制和候选读出的作用。

所有正式结构消融必须独立训练，再在相同test集上评价。加载full权重后切换baseline只属于推理期依赖性干预，不能替代“训练baseline”的结果。

## 2. 第一组：完整路径分解

| `cmt.mode` | 证据监督 | 特征融合 | 候选矩读出 | 回答的问题 |
|---|---|---|---|---|
| `baseline` | 无 | 无 | 无 | 同一语义检测器基础性能 |
| `evidence_aux` | 有 | 无 | 无 | 独立证据分支控制；不与语义骨干共享参数 |
| `feature_only` | 有 | 有 | 无 | 矩描述注入金字塔是否有用 |
| `readout_only` | 有 | 无 | 有 | 候选级精化是否有用 |
| `full` | 有 | 有 | 有 | 两条路径是否互补 |

`evidence_aux`的证据分支不会向独立语义骨干传梯度。因此它不是“共享骨干多任务学习”对照，而是额外独立辅助分支的负控制；应预期在随机性与数值差异之外没有直接检测收益。所有变体默认保留注册分支，尽量保持初始化顺序和状态字典可切换，但注册参数量不代表执行开销相同。

## 3. 第二组：机制分解

| 变体 | 配置 | 对照含义 / 注意事项 |
|---|---|---|
| 仅质量 | `cmt.compression=mass_only` | 取消单元内p/Q，保留质量和单元中心 |
| 一阶矩 | `cmt.order=1` | 保留m/p；协方差描述置零 |
| 二阶矩 | `cmt.order=2` | 默认；Q参与描述和可选误差证书 |
| 关闭原点变换 | `cmt.compression=no_origin` | 故意错误的负控制，仅用于证明坐标变换必要性，不能当成合理替代算法 |
| 直接像素状态 | `cmt.stride=1` | 不做空间压缩的强控制；计算更贵 |
| stride2 | `cmt.stride=2` | 2×2六矩对4像素可无损，不能声称同压缩率 |
| stride4 | `cmt.stride=4` | 主要研究设定 |
| stride8 | `cmt.stride=8` | 候选读出更粗；P2融合仍读取stride4状态 |
| 单窗口 | `cmt.support_factors=[1.5]` | 25维接口保留零填充，改变支持尺度数量 |
| 无gate | `cmt.gate=false` | 有效质量下始终使用证据质心偏移 |
| 无残差 | `cmt.residual=false` | 取消有界中心残差，框宽高仍可学习 |
| 无证据监督 | `train.heat_weight=0` | 检验显式背景/目标证据监督作用 |
| 无直接质心监督 | `train.centroid_weight=0` | 检验直接定位辅助监督 |
| 无gate监督 | `train.gate_weight=0` | gate仍受检测损失训练 |
| 无临时框监督 | `train.temporary_weight=0` | 检验语义初始框训练约束 |
| 无DN | `model.denoising=0` | 分离DN带来的收敛收益 |
| 无P2检测层 | `model.use_p2=false` | memory仅用P3–P5；浅层骨干仍计算，不等于完全删除浅层计算 |

部分参数只在相应路径生效。例如baseline改变gate没有意义；feature_only不经过候选读出，改变候选support不能解释融合收益。

二阶矩主要为协方差描述及误差分析提供信息；精确运输一阶矩即可计算单元权重下的质心。论文不能把“质心守恒”全部归因于二阶矩，必须报告一阶对照。

## 4. 第三组：非矩压缩控制

已有 `compression=learned`（分块stride卷积）与 `compression=spd`（PixelUnshuffle后1×1投影），输出同样8通道，适配器结构相同。它们只能和 `mode=feature_only/evidence_aux` 组合；自由学习通道不是有物理含义的m/p/Q，禁止直接送入矩质心公式。

公平比较先比较以下三项的feature_only：moments / learned / spd，固定同样的证据编码器和热图监督。再用full相对feature_only的增益评估矩读出。当前learned与spd均为线性分块投影，两者在相同stride下属于同一线性函数族，不能将两者都胜出解释为两种独立机制证据。

更强的同成本“自由候选特征读出”控制尚未实现；如果论文需要，应新增独立的候选特征聚合器及预测头，禁止把自由通道冒充原始矩。可插拔结构为该扩展留出了位置，但本轮未实现外部模型适配。

## 5. 生成与执行消融配置

从项目根目录执行：

```bash
python scripts/run_ablations.py --config configs/cmtdet_dev.yaml --data data/dut_coco/data.yaml --output runs/ablation_plan --variants baseline evidence_aux feature_only readout_only full --seeds 42 43 44
```

默认只保存完整YAML并打印训练命令，不启动训练。配置保存在输出目录的configs下；已存在的配置拒绝覆盖，避免意外改变实验定义。

需要实际顺序训练时使用新的输出目录并加 `--execute`：

```bash
python scripts/run_ablations.py --config configs/cmtdet_dev.yaml --data data/dut_coco/data.yaml --output runs/ablation_run --variants baseline feature_only readout_only full --seeds 42 43 44 --device cuda --execute
```

如果已经生成计划，可直接运行打印出的单条命令。脚本不自动调度多GPU，也不自动汇总不同训练结果。

对未列为脚本预设的粒度，用单独YAML或CLI：

```bash
python -m cmtdet train --config configs/cmtdet_dev.yaml --data data/dut_coco/data.yaml --output runs/no_p2_seed42 --set model.use_p2=false --set train.seed=42
python -m cmtdet train --config configs/cmtdet_dev.yaml --data data/dut_coco/data.yaml --output runs/no_heat_seed42 --set train.heat_weight=0.0 --set train.seed=42
```

各变体测试使用独立目录：

```bash
python -m cmtdet test --weights runs/ablation_run/full_seed42/best.pt --data data/dut_coco/data.yaml --split test --output runs/ablation_test/full_seed42
```

推理干预示例：

```bash
python -m cmtdet test --weights runs/ablation_run/full_seed42/best.pt --data data/dut_coco/data.yaml --split test --output runs/intervention/full_weights_baseline_path --set cmt.mode=baseline
```

这条结果必须写成“full权重关闭CMT”，不能标为“baseline独立训练”。测试时不允许覆盖宽度、层数、stride或损失参数。

## 6. 固定实验协议

1. 冻结train/val/test划分、标注转换坐标、类别表和输入尺寸；视频来源数据避免相邻帧跨划分泄漏。
2. 固定骨干预训练来源、有效batch、optimizer、LR、增强和总训练预算。容量变化额外报告参数与成本。
3. 每个变体至少3个seed，报告均值和标准差。应同时给固定预算结果及一致early-stop协议，避免更充分训练造成偏差。
4. 仅用val选择超参数与best，test用于最后比较；不能根据test tiny AP/PFR反复调support。
5. 报告COCO AP、AP_small、原框面积<100 AP/AR及对应GT数量。不同面积口径不要混用。
6. 相位稳健性另用冻结checkpoint和统一sampling-phase-sensitivity流程；本训练器的普通test不是相位实验。需要后续为此自定义检测器接入该实验框架。
7. 相位比较固定预处理、平移位置、有效区域、分组、匹配规则、阈值；同时报告召回/AP，避免全部漏检导致虚假的低翻转率。
8. 给出按图像或视频聚类的置信区间，避免把同一视频高度相关帧当成独立样本夸大显著性。

## 7. 建议论文主表与失败诊断

主表列：变体、seed数、AP50:95、AP_small、AP<100、AR<100、PFR、dropout、定位波动、实际执行参数/显存。相位指标尚未由本实现产生，不得填入推测值。

机制图建议对同一目标展示：E、单元m/p/Q、不同phase候选质心、gate、最终框；所有坐标先还原到共同原图。观察 `centroid_eligible`、质量不足比例与gate退化，区分“矩读出无信息”和“语义检测未收敛”。当前训练日志记录eligible数量；更细分的质量/gate分布可以从forward诊断另写分析脚本。

如果AP上升而PFR没有改善，只能说明检测收益，不能声称解决相位问题；如果PFR下降但AP下降，需排除低召回假稳定；如果只有stride1有效，应重新审视空间压缩是否损失关键证据，而不是忽略强对照。
